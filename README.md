# Moodnote

This beginner Angular app suggests songs for your mood. Choose **Chill**, **Happy**, or **Focused**, then click **Suggest another** to see another song.

This project uses Angular CLI 21.2.30.

## Development server

Install the packages and start the local server:

```bash
npm install
npm start
```

Open `http://localhost:4200/` in your browser. The app reloads when you change the code.

## Code scaffolding

To create a component, run:

```bash
ng generate component component-name
```

See more commands with `ng generate --help`.

## Building

```bash
npm run build
```

The build files are saved in `dist/moodnote/`.

## Running unit tests

```bash
npm test
```

## End-to-end tests

An end-to-end testing framework is not set up in this project.
